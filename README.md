Java 11, JUnit 4.13.2, maven 4.0.0, rest-assured 5.5.5

Проверяется:

Создание пользователя (CreatingAUserTest, CreatingAUserErrorTest):

создать уникального пользователя;
создать пользователя, который уже зарегистрирован;
создать пользователя и не заполнить одно из обязательных полей.

Логин пользователя (UserLoginTest):

вход под существующим пользователем;
вход с неверным логином и паролем.

Создание заказа (CreatingAnOrderTest, CreatingAnOrderParameterizedTest):

с авторизацией;
без авторизации;
с ингредиентами;
без ингредиентов;
с неверным хешем ингредиентов.
